## 1. PURPOSE

This Addendum grants Studio permission to reference the Project in Studio's portfolio, marketing materials, and public communications, subject to the terms below.

---

## 2. PERMITTED USES

Studio may:

| Use | Details | Approval Required |
|-----|---------|-------------------|
| **Project Summary** | High-level description (industry, challenge, approach, technologies) | ✅ Pre-approved |
| **Screenshots** | Studio-captured screenshots of public-facing interfaces | ✅ Per-use approval (email OK) |
| **Technology Stack** | List of technologies, frameworks, tools used | ✅ Pre-approved |
| **Team Credits** | Studio team member names/roles (no Client team without consent) | ✅ Pre-approved |
| **Metrics/Outcomes** | Publicly available metrics only (e.g., "launched on time") | ❌ Requires written approval per metric |
| **Client Name/Logo** | Display Client name/logo in portfolio | ❌ Requires written approval per use |
| **Case Study Article** | Detailed written case study | ❌ Requires written approval per article |
| **Verbal/Written References** | Studio team referencing project in proposals, talks | ❌ Requires written approval per instance |

---

## 3. APPROVAL PROCESS

### 3.1 Pre-Approved Uses (Section 2, ✅)
No further approval needed. Studio will notify Client before publication as a courtesy.

### 3.2 Approval-Required Uses (Section 2, ❌)
1. Studio sends draft (text, screenshots, layout) to Client's designated contact
2. Client reviews within **10 BUSINESS DAYS**
3. Client responds: **Approved / Approved with Changes / Declined**
3. If no response within 10 days → **Deemed Declined** (Studio will not publish)

### 3.3 Changes After Publication
Client may request modifications/removal at any time. Studio will comply within **10 BUSINESS DAYS**.

---

## 4. CONTENT GUIDELINES

Studio shall:
- Not disclose confidential information (pricing, internal metrics, proprietary algorithms, client PII)
- Not imply endorsement beyond what Client explicitly approves
- Anonymise any sensitive details (specific revenue, user counts, internal processes)
- Use only Studio-captured screenshots (no Client-provided assets without consent)
- Credit Client team members **only with their individual written consent**

---

## 5. ANONYMISATION OPTION

If Client declines name/logo usage, Studio may still reference the project as:
- "A [industry] client" / "A [region] [industry] company"
- "Confidential Client — [Industry]"
- With anonymised screenshots (logos/branding blurred)

---

## 6. DURATION

This Addendum remains in effect **indefinitely** unless terminated by either Party with **30 DAYS' written notice**. Permissions granted before termination survive for materials already published.

---

## 6. WITHDRAWAL

Client may withdraw permission for any specific use at any time by written notice. Studio will remove relevant content within **10 BUSINESS DAYS**.

---

## 7. NO ENDORSEMENT

Nothing in this Addendum implies Client's endorsement of Studio's services beyond the specific Project. Studio shall not state or imply Client endorses Studio generally.
